DAMD FULL TREASURY WALLET

1. Extract this folder. Open Command Prompt inside it (where package.json is).
2. Run: npm ci
3. Terminal 1: npm run chain (leave open).
4. Terminal 2: npm run deploy
5. Terminal 2: npm run dev
6. Open http://127.0.0.1:5173
7. MetaMask: RPC http://127.0.0.1:8545, chain ID 1337, symbol ETH.
8. Import the disposable development accounts printed by Terminal 1 into MetaMask only.
9. Connect owner 0. Deposit 1 test ETH. Propose 0.1 ETH to account 9.
10. Owners 1 and 2 approve. Wait 15 seconds. Execute as any owner.
